# Botão 3D Interativo
> Um projeto web simples, responsivo e interativo de um botão com efeito visual 3D, resposta sonora ao clique e geração de cores aleatórias para o plano de fundo.

## 🚀 Funcionalidades
Efeito Visual 3D: Simulação de profundidade e afundamento físico do botão ao ser pressionado (mousedown / mouseup).

Feedback Sonoro: Reprodução de efeito sonoro de clique a cada interação.

Cor de Fundo Dinâmica: Geração automática de cores hexadecimais aleatórias aplicadas ao body no momento da liberação do clique.

Design Responsivo: Adaptação para telas menores (smartphones e tablets) via @media queries.
